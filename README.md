# Proyecto Login y Registro en Flutter

## Descripción del proyecto

Este proyecto lo realicé para el taller de Maquetación Interactiva de Login y Registro. El objetivo es crear una aplicación en Flutter que permita navegar entre diferentes pantallas y validar la información ingresada por el usuario.

## Tecnologías utilizadas

- Flutter
- Dart
- Visual Studio Code
- Microsoft Edge

## Funcionalidades

La aplicación cuenta con las siguientes pantallas:

- **Login:** permite ingresar el correo electrónico y la contraseña.
- **Registro:** permite crear una cuenta ingresando los datos solicitados y aceptando los términos y condiciones.
- **Recuperar contraseña:** permite iniciar el proceso de recuperación.
- **Código de verificación:** permite ingresar un código de cuatro dígitos.
- **Nueva contraseña:** permite ingresar y confirmar una contraseña que cumpla los requisitos.
- **Home:** muestra un mensaje de bienvenida y el correo electrónico del usuario.

También incluye validaciones de los formularios, opciones para mostrar u ocultar la contraseña y botones para regresar entre las pantallas.

## Cómo ejecutar el proyecto

Para ejecutar la aplicación, se deben seguir estos pasos:

1. Clonar el repositorio de GitHub.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Abrir la terminal y ejecutar el siguiente comando para instalar las dependencias:

   ```bash
   flutter pub get
   ```

4. Ejecutar la aplicación en Microsoft Edge con el comando:

   ```bash
   flutter run -d edge
   ```

## Versiones utilizadas

Las versiones de Flutter y Dart se pueden consultar ejecutando el siguiente comando en la terminal:

```bash
flutter --version
```

## Observaciones

Este proyecto es académico y no utiliza una base de datos ni un backend. El inicio de sesión, el registro y el proceso de recuperación de contraseña funcionan de manera simulada.
